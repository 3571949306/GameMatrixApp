# 测试方案

> 生成时间：2026-06-19
> 任务目标：验证"移除美国 VPS 分发渠道"修改后项目可正常构建、启动、测试

---

## 一、构建命令

### 1.1 主构建命令
```bash
.\gradlew.bat :app:assembleDebug
```
- **用途**：编译 debug APK
- **预期**：BUILD SUCCESSFUL
- **产物**：`app/build/outputs/apk/debug/app-debug.apk`

### 1.2 Release 构建命令（可选）
```bash
.\gradlew.bat :app:assembleRelease
```
- **用途**：编译 release APK（需 keystore）
- **预期**：BUILD SUCCESSFUL
- **注意**：当前 `minifyEnabled false`，不触发 R8

### 1.3 清理构建
```bash
.\gradlew.bat clean
```
- **用途**：清理构建产物
- **使用场景**：怀疑缓存问题导致编译失败时

---

## 二、启动命令

### 2.1 安装到模拟器
```bash
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

### 2.2 启动 App
```bash
adb shell am start -n com.gamecenter.app/.SplashActivity
```

### 2.3 查看日志
```bash
adb logcat -s UpdateChecker UpdateDownloader RecoveryDownloader
```

## 三、测试命令

### 3.1 单元测试（主）
```bash
.\gradlew.bat :app:testDebugUnitTest
```
- **用途**：运行 app 模块单元测试
- **预期**：所有测试通过

### 3.2 单元测试（core:update）
```bash
.\gradlew.bat :core:update:testDebugUnitTest
```
- **用途**：运行 update 模块单元测试
- **预期**：所有测试通过

### 3.3 单元测试（core:common）
```bash
.\gradlew.bat :core:common:testDebugUnitTest
```
- **用途**：运行 common 模块单元测试
- **预期**：所有测试通过

### 3.4 Lint 检查
```bash
.\gradlew.bat :app:lintDebug
```
- **用途**：Android Lint 检查
- **预期**：无新增 error（warning 可接受）

### 3.5 特定测试类
```bash
.\gradlew.bat :app:testDebugUnitTest --tests "com.gamecenter.app.update.UpdateInfoTest"
.\gradlew.bat :app:testDebugUnitTest --tests "com.gamecenter.app.modules.ModuleManagerTest"
```

## 四、手动测试步骤

### 4.1 启动验证
1. 安装 debug APK 到模拟器
2. 启动 App
3. 验证 SplashActivity 正常显示
4. 验证 MainActivity 正常加载
5. 验证底部导航正常切换

### 4.2 设置页验证
1. 打开设置页
2. 点击"更新源"
3. **验证**：仅显示 3 个选项（自动/香港/GitHub），无"美国 VPS"
4. 选择"自动"
5. 验证设置保存成功

### 4.3 更新检查验证
1. 在设置页点击"检查更新"
2. 查看日志：`adb logcat -s UpdateChecker`
3. **验证**：日志中 `Build update URLs` 仅包含 HK VPS 和 GitHub 两个 URL
4. **验证**：无 US VPS URL 出现

### 4.4 模块商店验证
1. 打开模块商店
2. 下载一个模块（如 2048）
3. **验证**：下载成功
4. 查看日志：`adb logcat -s ModuleDownloader`
5. **验证**：仅尝试 HK VPS 源

### 4.5 恢复模式验证（可选）
1. 触发崩溃恢复
2. 查看日志：`adb logcat -s RecoveryDownloader`
3. **验证**：仅尝试 HK VPS 和 GitHub 两个源

## 五、自动测试步骤

### 5.1 编译测试
- 执行 `.\gradlew.bat :app:assembleDebug`
- 验证 BUILD SUCCESSFUL

### 5.2 单元测试
- 执行 `.\gradlew.bat :app:testDebugUnitTest`
- 验证所有测试通过
- 重点关注：
  - `UpdateInfoTest` — 更新信息解析
  - `ModuleManagerTest` — 模块管理
  - `GameRegistryTest` — 游戏注册
  - `PerfMonitorTest` — 性能监控

### 5.3 Lint 测试
- 执行 `.\gradlew.bat :app:lintDebug`
- 验证无新增 error

### 5.4 资源引用检查
- 编译时 AAPT 会检查资源引用
- 若 `settings_source_us_vps` 被删除但仍有引用，编译失败

## 七、测试失败处理

### 7.1 编译失败
1. 分析错误信息
2. 定位错误文件和行号
3. 修复代码
4. 重新编译
5. 记录到《测试报告.md》

### 7.2 测试失败
1. 分析失败测试用例
2. 判断是测试期望过时还是代码错误
3. 更新测试期望或修复代码
4. 重新运行测试
5. 记录到《测试报告.md》

### 7.3 运行时崩溃
1. 查看 `adb logcat` 日志
2. 定位崩溃堆栈
3. 修复代码
4. 重新安装验证
5. 记录到《测试报告.md》
