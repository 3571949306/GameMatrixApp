## 二、阶段 1：代码修改 - 移除 US VPS 三级源逻辑

### 阶段目标
移除 UpdateChecker、UpdateDownloader、RecoveryDownloader 中的 US VPS 三级源逻辑，改为 HK VPS → GitHub 两级源。

### 修改范围

#### 1.1 `core/update/src/main/java/com/gamecenter/app/update/UpdateChecker.java`
- **修改原因**：移除 US VPS 三级源逻辑
- **修改内容**：
  - L52-57：保留 `US_BASE_URL` 常量定义（为空字符串，向后兼容），添加 `@Deprecated` 注释
  - L98-101：移除 `SSLHelper.trustUpdateServer(US_BASE_URL)` 调用（空字符串无意义）
  - L318-378 `buildUpdateUrls()`：
    - 移除所有 `US_BASE_URL` 分支
    - `UPDATE_SOURCE_VPS_US` case 重定向到 `UPDATE_SOURCE_AUTO`（向后兼容）
    - 默认模式改为 HK → GitHub 两级
- **预期结果**：更新检查仅尝试 HK VPS 和 GitHub
- **验证方式**：编译通过 + 单元测试
- **风险点**：常量不能删除（SharedPreferences 已存储的值不能错位）
- **回退方式**：git checkout 该文件

#### 1.2 `core/update/src/main/java/com/gamecenter/app/update/UpdateDownloader.java`
- **修改原因**：移除 US VPS URL 构建
- **修改内容**：
  - L310-326 `buildDownloadUrls()`：移除 `usUrl` 构建和添加逻辑
  - L300-303 注释：更新为两级源说明
- **预期结果**：APK 下载仅尝试主 URL、GitHub、HK VPS
- **验证方式**：编译通过 + 单元测试
- **风险点**：低
- **回退方式**：git checkout 该文件

#### 1.3 `app/src/main/java/com/gamecenter/app/recovery/RecoveryDownloader.kt`
- **修改原因**：移除恢复模式 US fallback 源
- **修改内容**：
  - L21-31 `DOWNLOAD_SOURCES`：移除 `fallback` 插入逻辑
- **预期结果**：恢复模式仅尝试 HK VPS 和 GitHub
- **验证方式**：编译通过
- **风险点**：低
- **回退方式**：git checkout 该文件

#### 1.4 `app/src/main/java/com/gamecenter/app/App.java`
- **修改原因**：fallback host 将为空字符串，需验证 `SecureOkHttpFactory.setHosts()` 处理
- **修改内容**：
  - L103：保持调用，但添加空值保护注释
- **预期结果**：编译通过，运行时 fallback host 为空字符串
- **验证方式**：编译通过 + 运行时验证
- **风险点**：需确认 `SecureOkHttpFactory.setHosts()` 对空字符串的处理（应不报错）
- **回退方式**：git checkout 该文件

### 失败后处理方案

- 测试失败：分析测试用例，更新测试期望
