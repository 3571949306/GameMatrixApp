## 三、启动流程分析

### 3.1 入口

- **Application**：`com.gamecenter.app.App`（`@HiltAndroidApp`）
- **Launcher Activity**：`com.gamecenter.app.SplashActivity`（`android:noHistory="true"`）
- **主界面**：`com.gamecenter.app.MainActivity`

### 3.2 启动顺序

1. `App.attachBaseContext()` — 仅绑定 Context
2. `App.onCreate()`：
   - `CrashDetector.markAppStart()`
   - `applyLanguage()` — 应用语言
   - `applyTheme()` — 应用主题
   - `SecureOkHttpFactory.setHosts(BuildConfig.MODULE_HOST, BuildConfig.MODULE_FALLBACK_HOST)` — 注入安全主机
   - 注册 `ActivityLifecycleCallbacks`（应用配色方案）
3. `SplashActivity` → `MainActivity`
4. `MainActivity` 加载底部导航（游戏大厅、工具箱、浏览器、AI、VPN 等动态 Tab）
5. App Startup 延迟初始化 `OkHttpClientProvider`、`NetworkInitializer`

### 3.3 BuildConfig 注入的关键地址

| 字段 | 来源 | 默认值 |
|------|------|--------|
| `SERVER_URL` | `local.properties` → `server.url` | `https://your-server.example.com` |
| `SERVER_URL_FALLBACK` | `local.properties` → `server.url.fallback` | `""`（空） |
| `RELAY_URL` | `local.properties` → `relay.url` | `https://your-server.example.com/api/ddz-relay` |
| `WS_URL` | `local.properties` → `ws.url` | `""` |
| `FEEDBACK_URL` | `local.properties` → `feedback.url` | `https://your-server.example.com/api/feedback` |
| `MIMO_API_KEY` | `local.properties` → `mimo.api.key` | `""` |
| `MODULES_URL` | 派生自 `SERVER_URL` | `${SERVER_URL}/modules.json` |
| `DOWNLOAD_BASE_URL` | 派生自 `SERVER_URL` | `${SERVER_URL}/modules/` |
| `MODULE_HOST` | 派生自 `SERVER_URL` | URI host |
| `MODULE_FALLBACK_HOST` | 派生自 `SERVER_URL_FALLBACK` | URI host（空则回退主源） |
| `GITHUB_RELEASES_URL` | 硬编码 | `https://github.com/3571949306/GameMatrixApp/releases` |

## 五、风险点分析

### 5.1 高风险：分发渠道冗余（本次任务核心）

**现状**：项目实现了"三级下载源"架构（HK VPS → US VPS → GitHub），但用户要求**仅保留 HK VPS + GitHub**。

**影响范围**：

| 文件 | 风险点 |
|------|--------|
| `core/update/src/main/java/.../UpdateChecker.java` | L52-57 常量定义、L98-101 SSL 信任、L318-378 `buildUpdateUrls()` 三级源逻辑 |
| `core/update/src/main/java/.../UpdateDownloader.java` | L310-326 `buildDownloadUrls()` 三级源、L319 US URL 构建 |
| `core/common/src/main/java/.../SettingsManager.java` | L75 `UPDATE_SOURCE_VPS_US = 2` 常量 |
| `app/src/main/java/.../settings/AppSettingsDialog.java` | L49-56、L420-438 UI 显示"美国 VPS"选项 |
| `app/src/main/java/.../recovery/RecoveryDownloader.kt` | L21-31 `DOWNLOAD_SOURCES` 含 US fallback |
| `app/src/main/java/.../App.java` | L103 `SecureOkHttpFactory.setHosts()` 传入 fallback host |
| `app/src/main/res/values/strings.xml` | L249 `settings_source_us_vps` |
| `app/src/main/res/values-en/strings.xml` | L240 `settings_source_us_vps` |
| `app/build.gradle` | L198-209 `SERVER_URL_FALLBACK`、`MODULE_FALLBACK_HOST` BuildConfig |
| `core/update/build.gradle` | L80 `SERVER_URL_FALLBACK` BuildConfig |
| `app/version.gradle` | L15、L31、L67 fallback 读取 |
| `local.properties.template` | L21-22 `server.url.fallback` |
| `app/src/main/assets/modules.json` | 所有模块的 `fallbackUrl` 字段（当前为空） |
| `README.md` | 三级下载源架构图、VPS 职责划分表 |
| `docs/PROJECT_CONTEXT.md` | L349 `SERVER_URL_FALLBACK` 说明 |
| `docs/PUBLISH_GUIDE.md` | L80 fallback 配置示例 |
| `docs/refactor/track-vpn.md` | L201 三级源描述 |

**风险等级**：高
- 涉及核心更新链路，修改不当会导致用户无法更新
- 需要保持向后兼容（旧版本 App 仍可能请求 US VPS URL）
- 需要同步更新文档与配置模板

### 5.2 中风险：modules.json 单源问题

**现状**：`modules.json` 中所有模块的 `fallbackUrl` 和 `githubUrl` 字段均为空字符串，模块下载实际只有 HK VPS 单一源。

**影响**：HK VPS 不可用时，模块下载完全失败，无降级路径。

**建议**：本次任务可顺带为关键模块（games_hall、browser、tools、ai、vpn）填充 `githubUrl`，但需确认 GitHub Releases 是否已上传对应模块 APK。**若未确认，保持空字符串，避免下载失败**。

### 5.3 中风险：双 ModuleDownloader / 双 ModuleManifest 实现

**现状**：
- `app/src/main/java/.../modules/ModuleDownloader.kt` — 多源切换
- `app/src/main/kotlin/.../modular/ModuleDownloader.kt` — **仅单源**
- `app/src/main/java/.../modules/ModuleManifest.kt` — 含 githubUrl
- `core/module-host/.../ModuleManifest.kt` — **不含 githubUrl**

**影响**：代码冗余，维护成本高，行为不一致。

**建议**：本次任务不合并（避免大改），仅在文档中记录。

### 5.4 低风险：文档与代码不一致

- `docs/refactor/track-vpn.md` L201 描述三级源顺序与代码相反
- `README.md` 三级下载源架构图含"美国 VPS"，需更新为两级

### 5.5 低风险：构建状态

- `build_output2.txt` 显示最近一次 `:app:assembleDebug` 成功
- `build_output.txt` 显示历史一次失败（已修复，路径 `D:\kaifa\GameCenterApp` 是旧路径）
- 当前 `versionCode=448`，`versionName=1.4.0`

### 5.6 低风险：R8/ProGuard 临时关闭

- `app/build.gradle` L236-237：`minifyEnabled false`、`shrinkResources false`
- 注释说明是临时避开 `BreakoutActivity$1` 重复类问题
- 不影响功能，但 release 包体积偏大

## 六、本次任务范围确认

- 所有文档同步更新

**建议执行顺序**：先改代码 → 再改配置 → 再改文档 → 构建验证 → 测试验证 → 循环修复。
