# 浏览器模块变更日志

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块ID | browser |
| 模块类型 | nav（导航模块） |
| 入口类 | `BrowserModuleEntryPoint` |
| 入口方式 | 底部导航"浏览器"Tab → BrowserFragment |
| 模块商店分类 | browser |
| 是否内置 | 是（builtIn=true, isBaseFramework=true） |
| 当前版本 | v1.0.0 |
| 代码位置 | `app/src/main/java/com/gamecenter/app/fragments/BrowserFragment.java` |

## 功能概述

- 内置浏览器，支持多标签页、书签管理、文件下载和桌面/移动模式切换
- 基于 WebView 实现，支持 JavaScript、缩放、文件选择等
- 下载管理：支持文件下载和进度显示
- 安全检查：WebViewClient/WebChromeClient/DownloadListener 回调中添加 isAdded() && !isDestroyed 安全检查
- SSL 安全策略：不绕过 SSL 证书错误，遇到错误时取消加载并提示用户

---

## v1.0.1 — 2026-06-23

### 安全修复
- `BrowserFragment.onReceivedSslError` 由 `handler.proceed()` 改为 `handler.cancel()`，不再绕过 SSL 证书错误
- 添加 Toast 提示"SSL证书错误，已阻止不安全的连接"
- 添加 `Log.w` 错误日志记录出错 URL
- 符合 Google Play 政策与 Android 13+ 安全审计要求，避免应用被标记为高风险或被拒审

---

## v1.0.0 — 2026-05-24

### 稳定性修复
- BrowserFragment 添加 `isDestroyed` 标记，防止 Fragment 销毁后回调触发崩溃
- WebViewClient 回调中添加 `isAdded() && !isDestroyed` 安全检查
- WebChromeClient 回调中添加安全检查
- DownloadListener 回调中添加安全检查
- onDestroyView 中清理 WebView 引用

### 初始功能
- 多标签页浏览，支持新建、关闭、切换标签
- 书签管理，支持添加、删除、编辑书签
- 文件下载，支持下载进度显示和取消
- 桌面/移动模式切换
- 地址栏输入和搜索
- 历史记录
- 底部导航栏动态显示：安装浏览器模块后自动出现"浏览器"Tab
