# 错题本模块变更日志

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块ID | wrongbook |
| 模块类型 | nav（导航模块） |
| 入口类 | `WrongBookModuleEntryPoint` |
| 入口方式 | 底部导航"错题本"Tab → WrongBookFragment |

| 当前版本 | v1.0.0 |

## 功能概述

- 基于 AI 的错题整理与复习工具，支持拍照识题、OCR 识别、AI 解题分析
- Room v3 数据库（4 张表：Question / Subject / ReviewPlan / TopicMastery）
- 本地 ML Kit OCR + 云端扩展点双模式
- 艾宾浩斯遗忘曲线复习计划
- 自定义图表 View（掌握度分布 / 科目饼图 / 周趋势 / 庆祝动画）
- 科目管理、数据导入导出
- 浅色/深色主题、中英本地化
- 通过 Feature Flag `ENABLE_WRONGBOOK` 控制导航 Tab 注册

## v1.0.1 — 2026-07-11

- 预装模块改为使用宿主发布证书签名，并在打包时自动回填真实 `fileSize` 与 SHA-256。
- 下载与安装入口统一执行发布证书硬校验，签名异常直接拒绝。
- 后端 OCR/解题 POST 接口新增 `X-API-Key` 鉴权和每客户端限流。
- 安卓端直接 AI 密钥与后端访问令牌改为加密存储，移除普通 SharedPreferences 明文回退。
- 数据库更新为 v3，补齐结构化题目、OCR/AI 来源与置信度字段迁移。

## v1.0.0 — 2026-07-06

错题本模块初始版本，由循环 20-23 四轮迭代完成。

### 循环 20 — 预装集成
- 创建 wrongbook 动态模块工程：`module-store/feature/tools/wrongbook/`
- 实现 `WrongBookModuleEntryPoint`，实现 `ModuleInterface` + `FeatureModule`
- 宿主 `app/build.gradle` 新增 `ENABLE_WRONGBOOK` Feature Flag（默认 true）
- `MainActivity` 根据 `BuildConfig.ENABLE_WRONGBOOK` 与模块安装状态动态注册"错题本"导航 Tab
- 预装 APK 打包：`bundlePreinstalledModules` 任务将 `feature_wrongbook_v100.apk` 打入 `app/src/main/assets/modules/`
- 首次启动免下载即用

### 循环 21-22 — 核心功能
- **Room v2 Schema**：建立 4 张表（Question / Subject / ReviewPlan / TopicMastery），数据库 version=2
- **MIGRATION_1_2**：questions 表新增 isFavorite / sortOrder / tags 字段，注册迁移并以 fallbackToDestructiveMigration 兜底
- **OCR 双模式**：`OcrEngine` 接口 + `LocalMlKitOcrEngine` 本地实现 + `OcrService` 调度，预留云端扩展点
- **AI 分析集成**：`AiAnalysisService` 复用宿主 AI 多提供商能力，返回解题步骤与知识点归类
- **自定义图表 View**：
  - `MasteryDistributionView`：知识点掌握度分布
  - `SubjectPieChartView`：科目错题占比饼图
  - `WeeklyTrendChartView`：每周错题趋势折线
  - `CelebrationAnimationView`：复习完成庆祝动画
- **科目管理**：`SubjectManagementFragment` 增删改查科目
- **复习计划**：基于艾宾浩斯遗忘曲线自动生成复习节点，`ReviewFragment` 展示今日待复习
- **数据导入导出**：支持错题数据备份与迁移
- **主题与本地化**：浅色/深色主题（values / values-night），中英双语（values / values-en）

### 循环 23 — 体验完善
- **CaptureDialogFragment 5 步向导**：拍照/选图 → 裁剪 → OCR 识别 → AI 分析 → 保存归档
- **庆祝动画**：完成复习任务时触发 `CelebrationAnimationView`
- **ModuleContextHelper**：处理动态模块与宿主资源/上下文差异，解决动态加载环境下 Context 与资源访问问题
- 资源补全：14 个布局、10 个 drawable、菜单、dimens、styles
