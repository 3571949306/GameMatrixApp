## 全局兼容性适配

### Android 16+ 屏幕方向锁定 — 2026-06-23

Android 16+ (API 36) 起系统将忽略 manifest 中 `android:screenOrientation` 静态声明。已在所有游戏 Activity 的 `onCreate` 中通过 `setRequestedOrientation()` 运行时强制锁定方向（manifest 属性保留以兼容旧版本）：

- **竖屏游戏**：在 `BaseGameActivity.onCreate` 统一调用 `SCREEN_ORIENTATION_PORTRAIT`，覆盖所有继承该基类的游戏（共 25 个）。
- **横屏游戏**：`DouDiZhuActivity` 单独调用 `SCREEN_ORIENTATION_LANDSCAPE`。
- **直接继承 AppCompatActivity 的竖屏游戏**：`DouDiZhuMenuActivity`、`GomokuActivity` 单独调用 `SCREEN_ORIENTATION_PORTRAIT`。

详见 `修改记录.md` 循环11。

#### 2026-06-23 — 音效开关持久化
- `DouDiZhuActivity` 音效开关从 `DouDiZhuSoundManager` 内存变量改为读取 `SettingsManager.shouldPlayGameSound()` 持久化设置

- 播放前的开关判断由 `soundManager.isSoundEnabled()` 改为 `SettingsManager.getInstance(this).shouldPlayGameSound()`
- 保留原有 `DouDiZhuSoundManager` 播放调用逻辑不变，仅开关判断走 SettingsManager

#### 2026-06-23 — 音效与振动开关持久化
- `GomokuActivity` 音效/振动开关从内存变量（`soundEnabled`/`vibrateEnabled` 硬编码 `true`）改为读取 `SettingsManager` 持久化设置
- `initSoundAndVibration()` 初始化时从 `SettingsManager.getInstance(this).shouldPlayGameSound()` / `shouldVibrate()` 读取初始值
- 播放音效前的开关判断由 `!soundEnabled` 改为 `SettingsManager.getInstance(this).shouldPlayGameSound()`
- 执行振动前的开关判断由 `!vibrateEnabled` 改为 `SettingsManager.getInstance(this).shouldVibrate()`
- 保留原有 `SoundPool` 加载/播放与 `Vibrator` 初始化逻辑不变，catch 块中初始化失败标记逻辑保留
- 本 Activity 无音效/振动 UI 开关，开关由全局设置页统一管理

#### v2.1.0 — 2026-06-23
- AI引擎增强（`GomokuAI.java`），4档难度差异化更明显：
- 低难度随机走子：难度1有30%概率、难度2有15%概率从评分前3的着法中随机选一个，新手更容易获胜；难度3/4始终选最优
- 评估函数增强：新增"跳活三"（评分25000）和"跳冲四"（评分120000）间隔棋型识别，通过6格窗口扫描补充原有连续5格窗口扫描
- 开局首手随机偏移：棋盘为空时从天元及周围6个候选位置（共7个）中随机选一个，增加开局多样性
- 防守偏置按难度递减：难度1=1.40（保守重防守）、难度2=1.25、难度3=1.18、难度4=1.12（激进重进攻），替换原硬编码1.18/1.25
- 大师难度VCF算杀：难度4在迭代加深搜索前先尝试VCF（连续冲四必胜）搜索，深度6层（3回合），占用40%搜索时间预算，找到必胜路径直接返回首手
- 新增feature flag `vcfEnabled`，仅大师难度启用VCF
- 保持公共API不变：`getBestMove(GomokuGame, int)` 和构造函数 `GomokuAI(int)`
