### 移除所有可模块化游戏的宿主静态注册 — 2026-07-24

将宿主 `:app` 中所有已完成模块化的游戏的静态注册从 `GameRegistry.kt` 的 `buildStaticCategories()` 和宿主 `AndroidManifest.xml` 中注释移除，统一改为通过模块商店下载独立 APK 后由动态注册机制接入。仅保留未模块化的 `breakout`（打砖块）静态注册与 Activity 声明。

- classics（7）：gomoku / go / doudizhu / blackjack / checkers / dice / rock
