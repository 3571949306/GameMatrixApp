## 模块信息

| 属性 | 值 |
|------|-----|
| 模块ID | tools |
| 模块类型 | nav（导航模块） |
| 入口类 | `ToolsModuleEntryPoint` |
| 入口方式 | 底部导航"工具箱"Tab → ToolsFragment |
| 模块商店分类 | tool |
| 是否内置 | 是（builtIn=true, isBaseFramework=true） |
| 当前版本 | v1.1.0 |
| 代码位置 | `module-store/feature/tools/tools/src/main/java/com/gamecenter/app/fragments/ToolsFragment.java` |

## 功能概述

- 网络诊断、DNS查询、二维码扫描、电池信息、设备信息、传感器等30+实用工具
- 使用 ToolBinder 架构，每个工具独立绑定

## v1.1.0 — 2026-06-25

### 模块迁移
- 工具箱从 `:app` 主包迁移至 `module-store/feature/tools/tools/` 作为独立 APK 动态模块
- 代码位置由 `app/src/main/java/com/gamecenter/app/fragments/ToolsFragment.java` 迁移至 `module-store/feature/tools/tools/src/main/java/com/gamecenter/app/fragments/ToolsFragment.java`
- 入口类 `ToolsModuleEntryPoint` 迁移至 `module-store/feature/tools/tools/src/main/java/com/gamecenter/app/modules/`
- 所有 30+ ToolBinder 类随之迁移至 `module-store/feature/tools/tools/src/main/java/com/gamecenter/app/tools/`
- 沿用 `compileOnly` 依赖宿主接口，运行时由主 APK ClassLoader 提供
- 模块商店分发与预装接入

## v1.0.0 — 2026-05-24

### 稳定性修复
- ToolsFragment 中 `requireContext()` 替换为 `getContext()` 安全调用，防止 Fragment 未附加时崩溃

### 初始功能
- 30+ 实用工具，涵盖网络、扫描、设备、传感器、文本编码等分类
- ToolBinder 架构，每个工具独立绑定
- 底部导航栏动态显示：安装工具箱模块后自动出现"工具箱"Tab
