# 工具箱模块变更日志

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块ID | tools |
| 模块类型 | nav（导航模块） |
| 入口类 | `ToolsModuleEntryPoint` |
| 入口方式 | 底部导航"工具箱"Tab → ToolsFragment |
| 模块商店分类 | tool |
| 是否内置 | 是（builtIn=true, isBaseFramework=true） |
| 当前版本 | v1.0.0 |
| 代码位置 | `app/src/main/java/com/gamecenter/app/fragments/ToolsFragment.java` |

## 功能概述

- 网络诊断、DNS查询、二维码扫描、电池信息、设备信息、传感器等20+实用工具
- 使用 ToolBinder 架构，每个工具独立绑定

| 分类 | 工具 | 说明 |

| 设备 | 传感器 | 加速度、陀螺仪、磁力计等 |
| 其他 | 指南针 | 方向指示 |

## v1.0.0 — 2026-05-24

### 稳定性修复
- ToolsFragment 中 `requireContext()` 替换为 `getContext()` 安全调用，防止 Fragment 未附加时崩溃

### 初始功能
- 20+ 实用工具，涵盖网络、扫描、设备、传感器等分类
- ToolBinder 架构，每个工具独立绑定
- 底部导航栏动态显示：安装工具箱模块后自动出现"工具箱"Tab
