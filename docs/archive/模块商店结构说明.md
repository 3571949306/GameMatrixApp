## 目录说明

### 1. 压缩模块
- **位置**: `模块商店/压缩模块/`
- **内容**: 所有游戏模块的压缩包文件（.zip格式）
- **用途**: 这些是用户从模块商店下载的游戏模块文件
- **说明**: 原位置在 `deploy/modules/`，现在已移至此处（deploy目录仍保留备份）

### 2. 功能模块
- **位置**: `模块商店/功能模块/`
- **内容**: 
  - **游戏**: 独立游戏功能模块源代码
    - `games/chinesechess/`: 中国象棋模块（v2.0.0）
    - `games/game2048/`: 2048游戏模块
    - `games/klotski/`: 华容道模块（v2.0.0）
    - `games/src/`: 其他游戏源代码
  - **工具**: 工具功能模块
    - `vpn/`: 科学上网VPN模块
- **用途**: 这些是编译为独立APK后上传到模块商店的功能模块源代码
- **说明**: 原位置在 `feature/`，现在已移至此处

### 3. 模块清单
- **位置**: `模块商店/`
- **文件**: `modules.json` 和 `modules_v2.json`
- **用途**: 模块商店的配置文件，定义所有可用模块的元数据
- **说明**: 原位置在 `deploy/`，现在已复制到此处（deploy目录仍保留备份）

## 迁移说明

### 旧位置到新位置的映射
| 原位置 | 新位置 | 说明 |
|--------|--------|------|
| `deploy/modules/*.zip` | `模块商店/压缩模块/` | 游戏压缩模块 |
| `feature/games/` | `模块商店/功能模块/游戏/games/` | 游戏功能模块 |
| `feature/vpn/` | `模块商店/功能模块/工具/vpn/` | VPN功能模块 |
| `deploy/modules.json` | `模块商店/modules.json` | 模块清单（备份保留） |
| `deploy/modules_v2.json` | `模块商店/modules_v2.json` | 模块清单v2（备份保留） |

## 注意事项

1. **备份保留**: 原 `deploy/` 目录仍保留文件作为备份，方便回滚
2. **构建配置**: 需要检查并更新 `settings.gradle` 和相关构建配置，确保新路径被正确识别
3. **模块管理脚本**: `deploy/manage-modules.ps1` 等脚本可能需要更新路径引用
4. **模块发布流程**: 发布模块时，需要从新路径处理文件
