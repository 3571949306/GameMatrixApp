# 斗地主 Beta 联机架构改造说明

## 一、项目概述

### 1.1 项目信息
- **项目名称**：GameMatrixApp（游戏中心）
- **模块**：斗地主 Beta（DouDiZhu Beta）
- **改造目标**：将远程联机从 P2P/HTTP 轮询迁移到 WebSocket Client-Server 架构
- **改造时间**：2026-05-09 ~ 2026-05-10
- **版本**：vc=167, versionName=1.3.8, channel=beta

### 1.2 改造背景
原有联机架构存在以下问题：
- **P2P 直连**：NAT 穿透失败率高，不同网络环境下无法连通
- **HTTP 轮询**：延迟高（1-3秒），实时性差，用户体验不佳
- **连接不稳定**：无心跳机制，断线后无法自动恢复

### 1.3 改造目标
- ✅ 保持 LAN（局域网）功能完全不受影响
- ✅ 保持本地 TCP 联机功能不变
- ✅ 保留 HTTP Relay 作为 fallback
- ✅ 新增 WebSocket 作为主方案，实现低延迟实时通信
- ✅ 支持自动重连、心跳保活
- ✅ 跨跨境网络优化（中国 → 香港 VPS）
- ✅ 双端游戏状态完全同步

### 3.1 服务器架构（香港 VPS 主节点）

| 组件 | 技术 | 端口 | 说明 |

| Cloudflare | CDN + SSL | 443 | Flexible SSL 模式 |

### 3.2 关键配置文件

#### nginx WSS 配置 (`/etc/nginx/conf.d/03-hk-ws.conf`)
```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name hk-ws.<YOUR_DOMAIN>;

    ssl_certificate     /etc/nginx/ssl/cloudflare_origin.pem;
    ssl_certificate_key /etc/nginx/ssl/cloudflare_origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    location /ddz-ws {
        proxy_pass http://127.0.0.1:18080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
        proxy_send_timeout 86400;
    }
}
```

#### WebSocket Relay 服务 (`/var/www/update/ddz_ws_relay/server.js`)

**重要修复：** 所有消息转发使用 `data.toString('utf8')` 确保发送文本帧（不是二进制帧）。Node.js ws 库默认将 Buffer 作为二进制帧发送，OkHttp 的 `onMessage(WebSocket, String)` 只接收文本帧，导致 JOIN 消息丢失。

```javascript
// 客户端 → 房主转发（使用文本帧）
ws.on('message', (data) => {
    const msgStr = data.toString('utf8'); // 关键：转为字符串
    let t = '?'; try { t = JSON.parse(msgStr).type; } catch(e) {}
    
    if (room.host && room.host.readyState === 1) {
        room.host.send(msgStr); // 发送字符串 = 文本帧
        console.log(`RELAY->HOST: forwarded ${t}`);
    }
});
```

#### systemd 服务 (`/etc/systemd/system/GameMatrix-ddz-ws-relay.service`)
```ini
[Unit]
Description=GameMatrix DDZ WebSocket Relay
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/var/www/update/ddz_ws_relay
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```java
        if (roomStart > 0) {
```

### 4.5 RelayHttpClient.java 改动

```java
/**
 * 生成 WebSocket URL（房主端）
 */
public static String getWebSocketUrl(String baseUrl, String roomCode, String hostToken) {
    return buildWebSocketUrl(baseUrl, roomCode, "host", hostToken);
}

/**
 * 生成 WebSocket URL（客户端）
 */
public static String getWebSocketClientUrl(String baseUrl, String roomCode) {
    return buildWebSocketUrl(baseUrl, roomCode, "client", null);
}

/**
 * 通用 URL 构建方法
 */
private static String buildWebSocketUrl(String baseUrl, String roomCode, String role, String token) {
    String wsRoot = convertHttpToWs(baseUrl); // http→ws, https→wss
    StringBuilder sb = new StringBuilder();
    sb.append(wsRoot).append("/ddz-ws");
    sb.append("?room=").append(urlEncode(roomCode));
    sb.append("&role=").append(urlEncode(role));
    if (token != null && !token.isEmpty()) {
        sb.append("&token=").append(urlEncode(token));
    }
    return sb.toString();
}
```

### 5.2 已修复问题

| 问题 | 根因 | 修复方案 | 版本 |
|------|------|---------|------|
| 客户端转圈圈 | 客户端使用 `role=host` | 新增 `getWebSocketClientUrl()` 使用 `role=client` | vc=153 |
| JOIN 消息无 roomCode | `connectWebSocket()` 未设置 `relayRoomCode` | 从 wsUrl 提取 roomCode | vc=153 |
| 房主收不到 JOIN | 服务器检查 `clientId > 0` | 新增 `generateTempClientId()` 允许 -1 | vc=153 |
| JOIN 消息丢失 | Relay 转发 Buffer 为二进制帧，OkHttp 只处理文本帧 | Relay 使用 `data.toString('utf8')` 发送文本帧 | vc=167 |
| 游戏状态不同步 | Host 开房时没有 REMOTE 座位就开始游戏，广播 0 条消息 | 禁止在没有 REMOTE 座位时开始游戏 | vc=167 |
| 消息帧类型不匹配 | OkHttp 只实现 `onMessage(String)` | 新增 `onMessage(ByteString)` 处理二进制帧 | vc=167 |
