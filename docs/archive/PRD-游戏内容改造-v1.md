## 第一部分：通用框架（所有游戏共用）

### 1. 产品目标

为 GameCenterApp 的 27 个游戏提供统一的内容改造，提升用户体验和游戏质量。

**五大改造维度**：
1. **图标设计**：统一风格的游戏图标
2. **游戏规则**：完整的游戏规则说明
3. **教程系统**：交互式新手引导
4. **AI/难度**：智能难度调节系统
5. **成就系统**：激励性成就体系

### 2. 统一游戏模板架构

所有游戏使用统一的架构模板，确保代码一致性和可维护性：

```
GameTemplate/
├── BaseGameActivity.java          # 游戏基类 Activity
├── GameRulesFragment.java         # 规则说明页面
├── GameTutorialFragment.java      # 教程引导页面
├── GameAchievementManager.java    # 成就管理器
└── GameDifficultyManager.java     # 难度管理器
```

#### 2.1 BaseGameActivity — 游戏基类

**职责**：
- 管理游戏生命周期（开始、暂停、恢复、结束）
- 统一的游戏状态管理
- 集成成就系统和难度系统
- 提供通用 UI 组件（标题栏、计分板、计时器）

**核心方法**：
```java
abstract void initGame();           // 初始化游戏
abstract void startGame();          // 开始游戏
abstract void pauseGame();          // 暂停游戏
abstract void resumeGame();         // 恢复游戏
abstract void endGame();            // 结束游戏
abstract void checkAchievement();   // 检查成就
```

#### 2.2 GameRulesFragment — 规则说明页面

**职责**：
- 展示游戏规则（文字 + 图片）
- 支持多语言
- 支持规则版本管理

**UI 组件**：
- 规则标题
- 规则内容（支持富文本）
- 规则示意图
- 返回按钮

#### 2.3 GameTutorialFragment — 教程引导页面

**职责**：
- 交互式教程引导
- 步骤式教学（3-5 步）
- 支持跳过教程
- 教程完成状态记录

**UI 组件**：
- 步骤指示器
- 高亮提示区域
- 操作引导动画
- 下一步/跳过按钮

#### 2.4 GameAchievementManager — 成就管理器

**职责**：
- 管理游戏成就列表
- 监听游戏事件
- 解锁成就
- 显示成就弹窗
- 保存成就数据

#### 2.5 GameDifficultyManager — 难度管理器

**职责**：
- 管理难度级别（简单、普通、困难）
- 动态调整难度
- 记录玩家表现
- 提供难度选择 UI

#### 2.6 图标规范

**设计要求**：
- 格式：矢量 XML drawable
- 尺寸：48dp × 48dp
- 风格：Material Design
- 配色：护眼主题色系
- 命名：`ic_game_{game_id}.xml`

**示例**：
```xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="48dp"
    android:height="48dp"
    android:viewportWidth="24"
```

- **正文**：14sp，常规
- **辅助文字**：12sp，常规

### 1. 五子棋（gomoku）

#### 1.1 图标设计

**设计元素**：
- 棋盘格子（15×15 网格）
- 黑白棋子
- 胜利连线（五子连线）

**配色**：
- 棋盘：`#DEB887`（木纹色）
- 黑子：`#2D2D2D`（深灰）
- 白子：`#FFFFFF`（白色）
- 背景：`#F5F0E8`（暖米色）

#### 1.2 游戏规则

**基本规则**：
- 棋盘：15×15 网格
- 玩家：黑方先行，双方轮流落子
- 胜负：先连成五子者胜

**特殊规则**：
- 禁手规则（可选）：黑方有禁手（三三、四四、长连）
- 时间限制：每步限时 30 秒（可选）

**胜负判定**：
| 条件 | 结果 |
|------|------|
| 横向五子 | 胜利 |
| 纵向五子 | 胜利 |
| 斜向五子 | 胜利 |
| 棋盘填满 | 平局 |
| 超时 | 判负 |

**计分系统**：
| 结果 | 得分 |
|------|------|
| 胜利 | +100 分 |
| 平局 | +50 分 |
| 失败 | +0 分 |
| 连胜加成 | +20 分/连胜 |

#### 1.3 教程流程

**第 1 步：认识棋盘**
- 展示 15×15 棋盘
- 说明交叉点为落子位置
- 高亮棋盘中心点

**第 2 步：落子操作**
- 演示点击落子
- 说明黑白双方轮流
- 高亮最后落子位置

**第 3 步：五子连线**
- 演示横向五子
- 演示纵向五子
- 演示斜向五子
- 动画展示连线效果

**第 4 步：胜负判定**
- 演示胜利条件
- 展示胜利动画
- 说明平局条件

**第 5 步：开始游戏**
- 引导选择难度
- 开始第一局
- 提示可随时查看规则

#### 1.4 AI/难度设计

**难度级别**：

| 难度 | 描述 | AI 策略 |
|------|------|---------|
| 简单 | 适合新手 | 随机落子，偶尔防守 |
| 普通 | 有一定挑战 | 基础进攻 + 防守 |
| 困难 | 高手级别 | 进攻 + 防守 + 连子 |

**AI 策略**：
1. **进攻策略**：
   - 优先形成活四、冲四
   - 创造活三、跳三
   - 建立优势局面

2. **防守策略**：
   - 阻止对手形成活四
   - 封堵对手冲四
   - 破坏对手活三

3. **评估函数**：
   - 连子数量（权重最高）
   - 活子数量
   - 位置价值（中心权重高）

| 五子大师 | 赢得 10 局 | 🥈 银牌 |

### 2. 斗地主（doudizhu）

#### 2.1 图标设计

**设计元素**：
- 扑克牌（A 或大小王）
- 农民与地主形象
- 牌堆

**配色**：
- 牌背：`#1E3A5F`（深蓝色）
- 牌面：`#FFFFFF`（白色）
- 红色花色：`#E74C3C`（红心、方块）
- 黑色花色：`#2D2D2D`（黑桃、梅花）
- 背景：`#F5F0E8`（暖米色）

#### 2.2 游戏规则

**基本规则**：
- 玩家：3 人（1 地主 + 2 农民）
- 牌数：54 张（含大小王）
- 发牌：每人 17 张，底牌 3 张
- 目标：先出完手中牌者胜

**牌型**：
| 牌型 | 说明 | 示例 |
|------|------|------|
| 单张 | 任意一张牌 | 3 |
| 对子 | 两张相同点数 | 33 |
| 三条 | 三张相同点数 | 333 |
| 三带一 | 三条 + 一张 | 333+4 |
| 三带二 | 三条 + 一对 | 333+44 |
| 顺子 | 五张或更多连续单牌 | 34567 |
| 连对 | 三对或更多连续对子 | 334455 |
| 飞机 | 两个或更多连续三条 | 333444 |
| 飞机带翅膀 | 飞机 + 相同数量单牌/对子 | 333444+56 |
| 炸弹 | 四张相同点数 | 3333 |
| 火箭 | 大小王 | 🃏🃏 |

**出牌规则**：
- 必须大过上家牌型
- 炸弹可大过任何牌型（火箭除外）
- 火箭大过任何牌型

**胜负判定**：
| 条件 | 结果 |
|------|------|
| 地主先出完 | 地主胜利 |
| 任一农民先出完 | 农民胜利 |

**计分系统**：
| 结果 | 得分 |
|------|------|
| 地主胜利 | +200 分 |
| 农民胜利 | +100 分（每个农民） |
| 失败 | +0 分 |
| 炸弹加成 | +50 分/炸弹 |
| 火箭加成 | +100 分 |

#### 2.3 教程流程

**第 1 步：认识牌型**
- 展示所有牌型
- 说明牌型大小关系
- 高亮特殊牌型（炸弹、火箭）

**第 2 步：叫地主**
- 演示叫地主流程
- 说明叫地主策略
- 展示底牌翻开

**第 3 步：出牌操作**
- 演示选择牌型
- 演示出牌操作
- 说明"不出"操作

**第 4 步：胜负判定**
- 演示胜利条件
- 展示胜利动画
- 说明计分规则

**第 5 步：开始游戏**
- 引导选择难度
- 开始第一局
- 提示可随时查看规则

#### 2.4 AI/难度设计

**难度级别**：

| 难度 | 描述 | AI 策略 |
|------|------|---------|
| 简单 | 适合新手 | 随机出牌，偶尔出错 |
| 普通 | 有一定挑战 | 基础出牌策略 |
| 困难 | 高手级别 | 高级出牌策略 + 记牌 |

**AI 策略**：
1. **出牌策略**：
   - 优先出小牌
   - 保留炸弹关键时刻使用
   - 配合队友（农民 AI）

2. **叫地主策略**：
   - 根据手牌质量决定是否叫地主
   - 考虑牌型组合
   - 评估胜率

3. **记牌策略**：
   - 记录已出牌型
   - 推测对手手牌
   - 制定出牌计划

### 3. 中国象棋（chinesechess）

#### 3.1 图标设计

**设计元素**：
- 棋盘（9×10 网格）
- 楚河汉界
- 棋子（将/帅）

**配色**：
- 棋盘：`#DEB887`（木纹色）
- 红方：`#E74C3C`（红色）
- 黑方：`#2D2D2D`（深灰）
- 楚河汉界：`#8B7355`（深木色）
- 背景：`#F5F0E8`（暖米色）

#### 3.2 游戏规则

**基本规则**：
- 棋盘：9×10 网格
- 玩家：红方先行，双方轮流走棋
- 胜负：将死对方将/帅者胜

**棋子走法**：
| 棋子 | 走法 | 特殊规则 |
|------|------|----------|
| 将/帅 | 九宫格内一步 | 不能面对面 |
| 士 | 九宫格内斜走一步 | 不能出九宫格 |
| 象 | 斜走两格（田字） | 不能过河，不能蹩脚 |
| 马 | 日字走法 | 不能蹩脚 |
| 车 | 横竖任意格数 | 无 |
| 炮 | 横竖任意格数（吃子需隔一子） | 无 |
| 兵/卒 | 过河前只能前进，过河后可左右 | 不能后退 |

**胜负判定**：
| 条件 | 结果 |
|------|------|
| 将死对方将/帅 | 胜利 |
| 对方认输 | 胜利 |
| 超时 | 判负 |
| 困毙 | 胜利 |

**计分系统**：
| 结果 | 得分 |
|------|------|
| 胜利 | +100 分 |
| 平局 | +50 分 |
| 失败 | +0 分 |
| 连胜加成 | +20 分/连胜 |

#### 3.4 AI/难度设计

**难度级别**：

| 难度 | 描述 | AI 策略 |
|------|------|---------|
| 简单 | 适合新手 | 随机走棋，偶尔失误 |
| 普通 | 有一定挑战 | 基础走棋策略 |
| 困难 | 高手级别 | 高级走棋策略 + 搜索 |

**AI 策略**：
1. **走棋策略**：
   - 优先保护将/帅
   - 优先吃高价值棋子
   - 控制中心区域

2. **搜索策略**：
   - Minimax 算法
   - Alpha-Beta 剪枝
   - 搜索深度 3-5 层

3. **评估函数**：
   - 棋子价值（车 > 马 > 炮 > 兵）
   - 位置价值（中心权重高）
   - 安全性（将/帅保护）

### 4. 2048（game2048）

#### 4.1 图标设计

**设计元素**：
- 4×4 格子
- 数字方块（2048）
- 滑动箭头

**配色**：
- 背景：`#F5F0E8`（暖米色）
- 格子：`#CDC1B4`（浅棕色）
- 数字方块：渐变色（2-2048）

#### 4.2 游戏规则

**基本规则**：
- 棋盘：4×4 格子
- 操作：上下左右滑动
- 目标：合并数字达到 2048

**合并规则**：
| 操作 | 结果 |
|------|------|
| 滑动 | 所有方块向滑动方向移动 |
| 相同数字碰撞 | 合并为两数之和 |
| 每次滑动后 | 随机生成一个 2 或 4 |

**胜负判定**：
| 条件 | 结果 |
|------|------|
| 达成 2048 | 胜利（可继续游戏） |
| 棋盘填满且无法合并 | 失败 |

**计分系统**：
| 操作 | 得分 |
|------|------|
| 合并方块 | +合并后的数字 |
| 达成 2048 | +2048 分 |
| 达成 4096 | +4096 分 |

#### 4.3 教程流程

**第 1 步：认识棋盘**
- 展示 4×4 棋盘
- 说明数字方块
- 高亮初始方块

**第 2 步：滑动操作**
- 演示上下左右滑动
- 说明方块移动方向
- 展示滑动动画

**第 3 步：合并规则**
- 演示相同数字合并
- 说明合并后数字
- 展示合并动画

**第 4 步：新方块生成**
- 说明每次滑动后生成新方块
- 展示生成位置随机
- 提示策略建议

**第 5 步：开始游戏**
- 引导开始游戏
- 提示目标：2048
- 提示可随时查看规则

#### 4.4 AI/难度设计

**难度级别**：

| 难度 | 描述 | 说明 |
|------|------|------|
| 简单 | 适合新手 | 生成 4 的概率更高 |
| 普通 | 有一定挑战 | 标准规则 |
| 困难 | 高手级别 | 生成 4 的概率更低 |

**AI 辅助**：
- 提示下一步最佳移动
- 显示可能的合并路径
- 分析当前局面

#### 4.5 成就列表

| 成就名称 | 条件 | 级别 |
|----------|------|------|
| 初次合并 | 第一次合并方块 | 🥉 铜牌 |
| 达成 512 | 达成 512 分 | 🥈 银牌 |
| 达成 2048 | 达成 2048 分 | 🥇 金牌 |
| 达成 4096 | 达成 4096 分 | 🥇 金牌 |
| 高分达人 | 单局得分超过 10000 | 🥈 银牌 |
| 隐藏成就：完美合并 | 一局中所有合并都是最大值 | 🥚 彩蛋 |
