## 三、蓝蝶模拟器配置

### 3.1 安装蓝蝶模拟器国际版

1. **下载安装包**:
   - 访问蓝蝶模拟器官网
   - 下载"蓝蝶模拟器国际版"（Landie Emulator International）

2. **安装**:
   - 双击安装包
   - 按照向导完成安装
   - 记住安装路径（如 `C:\Program Files\LandieEmulator\`）

3. **配置环境变量**（可选）:
   - 将蓝蝶模拟器安装路径添加到 `PATH`
   - 例如: `C:\Program Files\LandieEmulator\`

### 3.2 创建模拟器实例

1. **打开蓝蝶模拟器**
2. **创建新实例**:
   - 点击"新建"
   - 选择设备: Pixel 5
   - 选择 Android 版本: 11 (API 30)
   - 设置内存: 2GB
   - 设置分辨率: 1080 x 1920
   - 命名: `Landie_Pixel_5`

3. **启动模拟器**:
   - 选择 `Landie_Pixel_5` 实例
   - 点击"启动"

### 3.3 启动双模拟器（端口 5554 和 5556）

**方法 1: 使用命令行启动**

1. **启动模拟器 A（端口 5554）**:
```bash
# 打开命令提示符（CMD）或 PowerShell
cd "C:\Program Files\LandieEmulator\"
LandieEmulator.exe -avd Landie_Pixel_5 -port 5554 -no-snapshot
```

2. **启动模拟器 B（端口 5556）**:
```bash
# 打开新的命令提示符（CMD）或 PowerShell
cd "C:\Program Files\LandieEmulator\"
LandieEmulator.exe -avd Landie_Pixel_5 -port 5556 -no-snapshot
```

3. **等待启动完成**（约 30 秒）

**方法 2: 使用 Python 脚本启动**

创建 `tools/start_landie_emulators.py`:
```python
# tools/start_landie_emulators.py
import subprocess
import time

def start_emulators():
    """启动两台蓝蝶模拟器"""
    print("🚀 启动蓝蝶模拟器...")
    
    # 模拟器 A - 端口 5554
    subprocess.Popen([
        'LandieEmulator.exe',
        '-avd', 'Landie_Pixel_5',
        '-port', '5554',
        '-no-snapshot'
    ])
    
    # 模拟器 B - 端口 5556
    subprocess.Popen([
        'LandieEmulator.exe',
        '-avd', 'Landie_Pixel_5',
        '-port', '5556',
        '-no-snapshot'
    ])
    
    # 等待启动完成
    print("⏳ 等待模拟器启动（30 秒）...")
    time.sleep(30)
    
    # 验证 ADB 连接
    result = subprocess.run('adb devices', shell=True, capture_output=True, text=True)
    print(result.stdout)
    
    if 'emulator-5554' in result.stdout and 'emulator-5556' in result.stdout:
        print("✅ 蓝蝶模拟器启动成功")
        return True
    else:
        print("❌ 蓝蝶模拟器启动失败")
        return False

if __name__ == '__main__':
    start_emulators()
```

运行脚本:
```bash
python tools/start_landie_emulators.py
```

## 四、ADB 配置

### 4.1 验证 ADB 连接

1. **打开命令提示符（CMD）或 PowerShell**
2. **执行命令**:
```bash
adb devices
```

3. **预期输出**:
```
List of devices attached
emulator-5554    device
emulator-5556    device
```

4. **如果看不到设备**:
   - 检查模拟器是否启动
   - 重启 ADB 服务:
```bash
adb kill-server
adb start-server
adb devices
```

### 4.2 ADB 常用命令

| 命令 | 说明 |
|------|------|
| `adb devices` | 列出所有连接的设备 |
| `adb -s emulator-5554 shell getprop ro.build.version.release` | 获取设备 Android 版本 |
| `adb -s emulator-5554 install -r app-debug.apk` | 安装 APK 到指定设备 |
| `adb -s emulator-5554 shell am start -n com.package/.ActivityName` | 启动 Activity |
| `adb -s emulator-5554 shell input tap 500 1000` | 点击屏幕坐标 |
| `adb -s emulator-5554 shell input text "hello"` | 输入文本 |
| `adb -s emulator-5554 exec-out screencap -p > screenshot.png` | 截图 |
| `adb -s emulator-5554 shell am force-stop com.package` | 关闭 APP |

## 六、项目编译环境配置

### 6.1 配置 local.properties

1. **打开 `local.properties` 文件**:
```bash
notepad local.properties
```

2. **配置 SDK 路径**:
```properties
# Windows 示例
sdk.dir=C\:\\Users\\YourName\\AppData\\Local\\Android\\sdk

# 或使用自定义 SDK 路径
# sdk.dir=D\:\\android-sdk
```

3. **保存文件**

### 6.2 配置 gradle.properties

1. **打开 `gradle.properties` 文件**:
```bash
notepad gradle.properties
```

2. **配置 Gradle 设置**:
```properties
# 使用 Gradle 构建缓存
org.gradle.caching=true

# 使用并行构建
org.gradle.paralel=true

# 配置 JVM 内存
org.gradle.jvmargs=-Xmx4096m -Dfile.encoding=UTF-8
```

3. **保存文件**

### 6.3 编译项目

1. **清理项目**:
```bash
.\gradlew clean
```

2. **编译 Debug 版本**:
```bash
.\gradlew assembleDebug
```

3. **验证编译成功**:
   - 检查 `app\build\outputs\apk\debug\app-debug.apk` 是否存在

## 九、常见问题排查

### 9.1 ADB 无法识别设备

**问题**: `adb devices` 看不到设备

**解决方案**:
1. 检查模拟器是否启动
2. 重启 ADB 服务:
```bash
adb kill-server
adb start-server
```
3. 检查防火墙是否阻止 ADB
4. 尝试使用 USB 连接（如果是真机）

### 9.2 Python 依赖安装失败

**问题**: `pip install` 失败

**解决方案**:
1. 使用国内镜像源:
```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple adbutils pytest
```
2. 升级 pip:
```bash
python -m pip install --upgrade pip
```
3. 使用虚拟环境:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 9.3 项目编译失败

**问题**: `.\gradlew assembleDebug` 失败

**解决方案**:
1. 检查 `local.properties` 配置
2. 检查 `gradle.properties` 配置
3. 清理项目:
```bash
.\gradlew clean
```
4. 查看详细错误日志:
```bash
.\gradlew assembleDebug --stacktrace
```
