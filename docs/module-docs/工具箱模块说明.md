# 工具箱模块说明

## 模块概述

工具箱模块集成了 26+ 实用工具（网络体检、DNS 查询、端口扫描、局域网发现、二维码/取色增强、文本编解码等）。

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块 ID | tools |
| 类型 | nav（导航模块） |
| 入口类 | `ToolsModuleEntryPoint` |
| 入口方式 | 底部导航栏"工具箱"Tab |
| 是否内置 | 内置代码，但按需启用（`builtIn=true` 模块） |

---

## 动态加载机制 (2026-05-23 优化)

工具箱已接入模块商店的 **动态 Tab 架构**：
1. **代码内置**：由于工具箱与系统服务（传感器、相机等）紧密结合，其源码和资源直接打包在 `:app` 主程序中。
2. **默认隐藏**：用户首次安装 App 时，底部导航栏默认只展示“游戏”Tab，工具箱处于隐藏状态。
3. **商店启用**：用户在模块大厅打开“模块商店”，找到工具箱模块，点击“启用”。此时 `ModuleManager` 会将其状态标记为已启用，并通知 `MainActivity` 动态刷新底部导航栏，显示“工具箱”Tab。

## 核心工具分类

### 1. 网络工具
Ping、端口扫描、路由追踪、DNS 查询/Lookup、局域网设备扫描、子网计算器、IP 查询、综合网络诊断、网络测速、WiFi 扫描。

### 2. 安全与隐私工具
权限与隐私检查（查看和管理摄像头、定位等权限）、多算法哈希计算、文件哈希值计算。

### 3. 日用与设备工具
二维码生成与识别（增强版）、剪贴板管理、颜色取色器（支持对比度检测与多格式转换）、文本/Base64/URL 编解码、电池健康与传感器实时监控、导出系统诊断报告。
