# 工具箱模块说明

## 模块概述

工具箱模块集成了 30+ 实用工具（网络体检、DNS 查询、端口扫描、局域网发现、二维码/取色增强、文本编解码、JSON 格式化、正则测试等）。

## 动态加载机制

工具箱已从 `:app` 主包迁移至 `module-store/feature/tools/tools/` 作为独立 APK 模块：

1. **独立 APK**：工具箱源码与资源编译为独立 APK，通过模块商店分发与预装。
2. **默认隐藏**：用户首次安装 App 时，底部导航栏默认不展示"工具箱"Tab。
3. **商店启用**：用户在模块大厅打开"模块商店"，找到工具箱模块，点击"启用"。此时 `ModuleManager` 会将其状态标记为已启用，并通知 `MainActivity` 动态刷新底部导航栏，显示"工具箱"Tab。
4. **动态宿主**：模块加载后由 `ModuleShellFragment` 作为宿主承载 `ToolsFragment`，通过 `FeatureModule.createFragment()` 返回。

## 核心工具分类（30+）

### 1. 网络工具
Ping（`PingToolBinder`）、端口扫描（`PortScanToolBinder`）、路由追踪（`TracerouteToolBinder`）、DNS 查询（`DnsLookupToolBinder`）、DNS 工具（`DnsToolBinder`）、局域网设备扫描（`LanScanToolBinder`）、子网计算器（`SubnetToolBinder`）、IP 查询（`IpToolBinder`）、综合网络诊断（`NetworkDiagnosisToolBinder`）、网络测速（`SpeedTestToolBinder`）、WiFi 扫描（`WifiToolBinder`）。

### 2. 安全与隐私工具
权限与隐私检查（`PermissionPrivacyToolBinder`）、多算法哈希计算（`HashToolBinder`）、文件哈希值计算（`FileHashToolBinder`）。

### 3. 日用与设备工具
二维码生成与识别（`QrToolBinder`）、二维码增强（`QrPlusToolBinder`）、剪贴板管理（`ClipboardToolBinder`）、颜色取色器（`ColorPickerToolBinder`）、取色增强（`ColorPlusToolBinder`）、电池信息（`BatteryToolBinder`）、设备信息（`DeviceToolBinder`）、系统信息（`SystemInfoToolBinder`）、传感器监控（`SensorToolBinder`）、屏幕工具（`ScreenToolBinder`）、导出系统诊断报告（`DiagnosticReportToolBinder`）。

### 4. 文本与编码工具
文本/Base64 编解码（`Base64ToolBinder`）、文本编解码（`TextCodecToolBinder`）、URL 编解码（`UrlEncodeToolBinder`）、JSON 格式化（`JsonFormatToolBinder`）、正则测试（`RegexTestToolBinder`）。
