# 游戏模块说明

## 模块概述

游戏模块是 GameCenterApp 的核心模块。在最新的项目架构下，除了**五子棋**和**斗地主**保留在 `:app` 主包中之外，其余小游戏（共 28 款，包含华容道、中国象棋、飞刀大师等）已全部从主包剥离，并托管于模块商店中。

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块 ID | game |
| 类型 | nav（导航模块）/ 独立加载模块 |
| 入口方式 | 游戏大厅 Fragment → 游戏卡片点击 |
| 是否内置 | 双轨制：经典游戏内置；其余小游戏从模块商店下载 |
| 模块商店路径 | `GameCenterApp/模块商店/功能模块/游戏/games/` |

---

## 游戏分类与部署方式

### 1. 内置于主包中的经典游戏
这些游戏直接内置在 `:app` 壳应用中，无需下载即可游玩：

*   **五子棋 (`Gomoku`)** - 支持人机对战与 WebSocket 联机
*   **斗地主 (`DouDiZhu`)** - 支持单机人机与三模联机（局域网/HTTP Relay/WebSocket）

### 2. 模块商店动态下载/注册的游戏
其它所有小游戏均已完成模块化剥离，并在大厅启动时通过 `GameRegistry` 进行动态注册：

*   **独立 APK 模块**：如**华容道** (`klotski`)、**中国象棋** (`chinesechess`)、**飞刀大师** (`knife`) 等。它们作为独立功能模块存放于 `模块商店/功能模块/游戏/games/`，编译打包成 `.zip` 压缩包存放在 `模块商店/压缩模块/` 中，供客户端从 VPS 动态下载加载。
*   **大厅回流注册**：所有下载安装成功的游戏模块会自动注册回游戏大厅并正常显示卡片，卸载时会同步注销。

## 核心架构与类说明

以下共享基础设施位于游戏模块或基础库中，被各游戏组件复用：

| 类/接口名 | 说明 |
|----------|------|
| [GameRegistry.kt](file:///d:/Developmment/GameMatrixApp/app/src/main/kotlin/com/gamecenter/app/games/GameRegistry.kt) | 游戏注册中心（已 Kotlin 化），支持静态注册、注解自动发现（`@GameEntry`）及已下载模块动态注册 |
| [DynamicGameActivity](file:///d:/Developmment/GameMatrixApp/app/src/main/java/com/gamecenter/app/DynamicGameActivity.java) | 壳 Activity，用于动态承载并启动各个剥离的小游戏 Fragment |
| `BaseGameActivity` | 所有内置/外置游戏的共享基类，提供统一的音效、震动、动画调用接口 |
| `OnlineRoomManager` | 联机房间管理器（组合式设计，替换了历史的 BaseOnlineActivity 继承） |
