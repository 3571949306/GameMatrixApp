# 浏览器模块说明

## 模块概述

浏览器模块是内置的网页浏览工具，提供多标签页管理、书签、文件下载和桌面/移动模式切换功能。

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块 ID | browser |
| 类型 | nav（导航模块） |
| 入口类 | `com.gamecenter.app.browser.ui.BrowserModuleEntryPoint` |
| 入口方式 | 底部导航栏"浏览器"Tab |
| 是否内置 | 内置代码，但按需启用（`builtIn=true` 模块） |
| 代码位置 | `app/src/main/java/com/gamecenter/app/browser/` |
| 当前版本 | v2.0.0（循环19 原生重构） |

---

## 动态加载机制 (2026-05-23 优化)

浏览器已接入模块商店的 **动态 Tab 架构**：
1. **代码内置**：浏览器的核心网络交互、Cookie 同步、WebView 实例化逻辑打包在主 APK 中。
2. **默认隐藏**：首次启动时，底部导航栏隐藏“浏览器”Tab。
3. **商店启用**：用户在模块商店将浏览器标记为“启用”后，客户端会通知 `MainActivity` 动态在底部导航栏追加“浏览器”Tab，实现按需展示。

---

## 功能列表

*   **多标签页管理**：支持同时打开多个网页，进行卡片式多标签页切换和删除。
*   **地址栏搜索与联想**：支持自动补全 URL，集成通用搜索引擎并根据输入字词提供实时联想词。
*   **书签与历史**：本地保存书签，支持快捷添加/删除，以及完整的历史浏览记录查询。
*   **文件下载**：拦截网页下载链接，自动调用系统下载器或 App 下载线程，将文件下载到外部存储。
*   **User-Agent 切换**：支持一键在手机移动版视图与电脑桌面版视图之间切换。

## 循环19 原生重构 (v2.0.0)

浏览器模块在循环19 完成原生重构，代码从单一 Fragment 拆分为 `browser/` 下的 5 个子包，分层清晰：

### 子包结构

| 子包 | 说明 |
|------|------|
| `browser/bridge/` | JS 桥接（`BrowserJsBridge`） |
| `browser/core/` | 浏览器核心（缓存、ChromeClient、Controller、Settings、TabManager、WebViewClient） |
| `browser/data/` | Room 数据层（DAO、Entity、Repository、Database、DownloadManager） |
| `browser/security/` | 安全模块（广告拦截、安全策略、域名信任、JS 桥接策略） |
| `browser/ui/` | 界面层（Fragment、Activity、Adapter、Dialog） |
| `browser/util/` | 工具类（`UrlUtils`） |

### Room 数据层（4 张表）

| 表 / Entity | DAO | 说明 |
|------|------|------|
| `BrowserBookmarkEntity` | `BrowserBookmarkDao` | 书签 |
| `BrowserDownloadEntity` | `BrowserDownloadDao` | 下载记录 |
| `BrowserHistoryEntity` | `BrowserHistoryDao` | 浏览历史 |
| `SearchHistoryEntity` | `SearchHistoryDao` | 搜索历史 |

数据库由 `BrowserDatabase` 统一管理，`BrowserBookmarkRepository` / `BrowserHistoryRepository` / `SearchHistoryRepository` 封装数据访问，下载由 `BrowserDownloadManager` 管理。

### 安全模块

| 类 | 说明 |
|----|------|
| `AdBlocker` | 广告拦截，基于规则过滤广告请求 |
| `BrowserSecurityPolicy` | 浏览器安全策略总控 |
| `DomainTrustManager` | 域名信任管理，区分可信与不可信站点 |
| `JsBridgePolicy` | JS 桥接安全策略，控制 `BrowserJsBridge` 暴露面 |

### Activity 列表

| Activity | 说明 |
|------|------|
| `BrowserActivity` | 浏览器主 Activity |
| `BookmarkActivity` | 书签管理 |
| `BrowserSettingsActivity` | 浏览器设置 |
| `DownloadActivity` | 下载管理 |
| `HistoryActivity` | 历史记录 |
| `TabManagerActivity` | 标签页管理 |
