# 错题本模块说明

## 模块概述

错题本模块是基于 AI 的错题整理与复习工具，提供拍照识题、OCR 文本识别、AI 分析解题、艾宾浩斯复习计划、科目管理、自定义图表可视化与数据导入导出等能力。该模块在循环 20-23 期间完成开发与预装集成，是工具类动态模块的重要组成。

## 架构说明

错题本模块采用三层架构，代码位于 `module-store/feature/tools/wrongbook/src/main/java/com/gamecenter/app/wrongbook/` 下：

### 1. analysis 层（分析与识别）

| 类 | 说明 |
|----|------|
| `OcrEngine` | OCR 引擎接口，定义识别契约 |
| `LocalMlKitOcrEngine` | 本地 ML Kit OCR 引擎实现，离线识别 |
| `OcrService` | OCR 服务统一入口，调度引擎 |
| `OcrResult` | OCR 识别结果数据模型 |
| `AiAnalysisService` | AI 分析服务，对接云端大模型进行解题分析 |

### 2. data 层（数据持久化）

| 类 | 说明 |
|----|------|
| `QuestionEntity` | 错题实体（题目、图片、答案、标签、收藏、排序等） |
| `SubjectEntity` | 科目实体 |
| `ReviewPlanEntity` | 复习计划实体（艾宾浩斯周期） |
| `TopicMasteryEntity` | 知识点掌握度实体 |
| `WrongBookDao` | Room 数据访问对象 |
| `WrongBookDatabase` | Room 数据库（version=2，含 MIGRATION_1_2） |
| `WrongBookRepository` | 数据仓库，封装 DAO 访问 |

### 3. ui 层（界面）

| 类 | 说明 |
|----|------|
| `BaseWrongBookFragment` | Fragment 基类，提供公共能力 |
| `WrongBookFragment` | 模块主 Fragment，承载 Tab 与导航 |
| `WrongBookViewModel` | 主 ViewModel |
| `DashboardFragment` | 仪表盘首页（图表总览） |
| `QuestionsFragment` | 题目列表 |
| `ReviewFragment` | 复习页 |
| `SearchFragment` | 搜索页 |
| `SettingsFragment` | 设置页 |
| `SubjectManagementFragment` | 科目管理 |
| `CaptureDialogFragment` | 5 步拍照向导 Dialog |
| `QuestionDetailDialogFragment` | 题目详情 Dialog |
| `FullscreenImageDialogFragment` | 全屏图片查看 Dialog |
| `QuestionAdapter` / `ReviewAdapter` / `TopicMasteryAdapter` | 列表适配器 |
| `ModuleContextHelper` | 模块上下文助手，处理动态模块与宿主资源/上下文差异 |

## Room v2 Schema 说明

错题本数据库使用 Room 2.7.x，数据库名 `wrongbook.db`，存放在宿主 App 私有目录，避免模块卸载后数据丢失。

### 数据表（4 张）

| 表名 | 实体 | 说明 |
|------|------|------|
| `questions` | `QuestionEntity` | 错题主表，含题目文本、图片路径、答案、科目、知识点、收藏、排序、标签 |
| `subjects` | `SubjectEntity` | 科目表 |
| `review_plans` | `ReviewPlanEntity` | 复习计划表，按艾宾浩斯遗忘曲线生成复习节点 |
| `topic_mastery` | `TopicMasteryEntity` | 知识点掌握度表 |

### MIGRATION_1_2

从 v1 升级到 v2 时为 `questions` 表新增字段：
- `isFavorite INTEGER NOT NULL DEFAULT 0`（收藏标记）
- `sortOrder INTEGER NOT NULL DEFAULT 0`（排序）
- `tags TEXT NOT NULL DEFAULT ''`（标签）

数据库构建时通过 `addMigrations(MIGRATION_1_2)` 注册迁移，并以 `fallbackToDestructiveMigration()` 作为兜底。

## OCR 双模式

错题本支持双模式 OCR 识别：

1. **本地 ML Kit OCR**：通过 `LocalMlKitOcrEngine` 调用 ML Kit Text Recognition，完全离线运行，无需联网，保护隐私。默认启用。
2. **云端扩展点**：`OcrEngine` 接口预留云端 OCR 接入能力，可在后续版本通过 `OcrService` 注入云端引擎实现高精度识别。

`OcrService` 作为统一调度入口，根据配置与可用性选择引擎，对调用方屏蔽底层差异。

---

## AI 分析集成

`AiAnalysisService` 负责将 OCR 识别出的题目文本提交给 AI 进行分析：

- 复用宿主 AI 模块的多提供商能力（DeepSeek / 通义 / 硅基流动 / 智谱 / 零一万物 / OpenAI）
- 返回解题步骤、知识点归类与难度评估
- 分析结果回写至 `QuestionEntity`，并联动 `TopicMasteryEntity` 更新掌握度
- 结合 `ReviewPlanEntity` 按艾宾浩斯遗忘曲线生成复习提醒

## 自定义图表 View

仪表盘 (`DashboardFragment`) 使用 4 个自定义 View 进行数据可视化：

| View | 说明 |
|------|------|
| `MasteryDistributionView` | 知识点掌握度分布图 |
| `SubjectPieChartView` | 科目错题占比饼图 |
| `WeeklyTrendChartView` | 每周错题趋势折线图 |
| `CelebrationAnimationView` | 完成复习任务时的庆祝动画 |

所有图表 View 自绘实现，无第三方图表库依赖，同时适配浅色与深色主题。

## 核心功能

### 科目管理
- 通过 `SubjectManagementFragment` 增删改查科目
- 每道题归属一个科目，支持按科目筛选与统计

### 复习计划
- 基于艾宾浩斯遗忘曲线自动生成复习节点
- `ReviewFragment` 展示今日待复习题目
- 完成复习后触发 `CelebrationAnimationView` 庆祝动画

### 数据导入导出
- 支持错题数据导出（便于备份与迁移）
- 支持导入已有错题数据

### 拍照识题向导
`CaptureDialogFragment` 提供 5 步向导流程：拍照/选图 → 裁剪 → OCR 识别 → AI 分析 → 保存归档。

## 预装与 Feature Flag

### Feature Flag
- 宿主 `app/build.gradle` 中定义 `buildConfigField "boolean", "ENABLE_WRONGBOOK", "true"`
- `MainActivity` 中通过 `BuildConfig.ENABLE_WRONGBOOK` 控制是否注册"错题本"Tab
- 仅当 flag 为 true 且模块已安装/预装时，底部导航栏才显示"错题本"入口

### 预装 APK
- 预装文件：`app/src/main/assets/modules/feature_wrongbook_v100.apk`
- 构建时由 `bundlePreinstalledModules` 任务将 wrongbook 模块 APK 打包进主 APK assets
- 首次启动时宿主自动从 assets 解包并加载，实现免下载即用
