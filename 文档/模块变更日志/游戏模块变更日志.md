# 游戏模块变更日志

## 模块信息

| 属性 | 值 |
|------|-----|
| 模块ID | game |
| 模块类型 | nav（导航模块） |
| 入口方式 | 游戏大厅 Fragment → 游戏卡片点击 |
| 模块商店分类 | game |
| 是否内置 | 是（isBaseFramework=true） |
| 当前状态 | 内置在 `:feature:games` 中 |
