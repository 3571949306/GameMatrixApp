## 部署流程总结

### 1. 文件移动
```bash
# 移动源代码到模块商店目录
$ Move-Item app/src/main/java/com/gamecenter/app/games/knife/* 
  → 模块商店/功能模块/游戏/games/src/main/java/com/gamecenter/app/games/knife/

# 删除原位置
$ Remove-Item app/src/main/java/com/gamecenter/app/games/knife/
```

### 2. 创建压缩包
```bash
$ Compress-Archive -Path "knife/*" -DestinationPath "game_knife_v100.zip"
```

### 3. 上传到VPS
```bash
# 上传游戏压缩包
$ scp game_knife_v100.zip root@149.104.29.181:/var/www/update/modules/

# 复制到模块目录
$ ssh root@149.104.29.181 "cp /var/www/update/modules/game_knife_v100.zip /var/www/modules/"

# 上传modules.json
$ scp modules.json root@149.104.29.181:/var/www/update/modules.json
$ ssh root@149.104.29.181 "cp /var/www/update/modules.json /var/www/modules/store.json"
```

### 4. 启动服务
```bash
# 重启模块服务器
$ ssh root@149.104.29.181 "pkill -f 'python3.*http.server'; 
  cd /var/www/update; nohup python3 module_server.py > /var/log/module_server.log 2>&1 &"

# 重启Nginx
$ ssh root@149.104.29.181 "systemctl restart nginx"
```

### 5. 配置修复

# 修复nginx proxy_pass配置
$ ssh root@149.104.29.181 "sed -i 's|proxy_pass http://127.0.0.1:9001;|proxy_pass http://127.0.0.1:9001/;|g' /etc/nginx/conf.d/02-hk-update.conf"

## 用户使用指南

### 从模块商店下载
1. 打开 GameMatrixApp
2. 进入游戏大厅
3. 点击左上角版本号进入模块商店
4. 在"游戏"分类中找到"飞刀大师"
5. 点击"下载"按钮
6. 下载完成后，游戏会自动注册到游戏大厅

### 游戏玩法
1. 点击屏幕投掷飞刀
2. 飞刀需要插入靶子缝隙，不能与已有飞刀重叠
3. 击中旋转的苹果获得额外分数
4. 连续成功插入获得连击加成
5. 每过一关，难度逐渐增加
