# 夹层（GameMatrix）

一个把休闲游戏、实用工具和可选扩展放在一起的 Android 应用。

[下载最新版本](https://github.com/3571949306/GameMatrixApp/releases/latest) ·
[查看本次更新](RELEASE_NOTES.md) ·
[反馈问题](https://github.com/3571949306/GameMatrixApp/issues)

## 你可以用它做什么

### 玩游戏

- 五子棋、围棋、中国象棋、斗地主、2048
- 贪吃蛇、俄罗斯方块、数独、扫雷、推箱子等休闲游戏
- 部分游戏支持人机对战或联网对战
- 自动记录最近游玩、游戏时长和部分游戏数据

### 按需添加功能

应用内提供模块商店，不需要的功能可以不安装。

- 浏览和搜索可用模块
- 安装、更新或卸载扩展
- 添加新的游戏、工具、浏览器、AI 助手等功能
- 自定义底部导航的显示内容和顺序

### 使用常用工具

- 二维码生成与识别
- 网络检测、DNS 查询、端口扫描
- 设备、电池和网络信息
- Base64、URL、JSON、时间戳等常用处理
- 文件哈希和颜色工具
- 错题记录、科目管理与复习计划

部分工具或服务需要联网，也可能需要单独安装对应模块。

## 下载与安装

1. 打开[最新版本页面](https://github.com/3571949306/GameMatrixApp/releases/latest)。
2. 下载 `app-release.apk`。
3. 点击 APK 并按系统提示完成安装。
4. 如果系统拦截安装，请只为当前使用的浏览器或文件管理器开启“允许安装未知应用”。

直接安装新版可以保留原有应用数据。请不要先卸载旧版，除非应用明确提示必须重新安装。

当前正式 APK 面向 64 位 ARM Android 设备，要求 Android 7.0 或更高版本。

## 更新应用

你可以在应用设置中检查更新。默认接收稳定版；如果主动开启测试版更新，可能会更早体验新功能，但稳定性也可能稍低。

为避免下载到被修改的安装包，请优先使用：

- 应用内更新
- 本仓库的 [GitHub Releases](https://github.com/3571949306/GameMatrixApp/releases)

## 权限说明

应用只会在相关功能需要时请求权限：

| 权限 | 用途 |
|---|---|
| 相机 | 扫描二维码、拍摄错题等 |
| 麦克风 | 语音相关功能 |
| 照片与文件 | 导入、导出或选择图片 |
| 位置与附近网络 | Wi-Fi、局域网发现等 Android 系统要求的功能 |
| 通知 | 显示下载、更新或重要状态 |
| 安装应用 | 安装你主动下载的应用更新 |

你可以随时在 Android 系统设置中关闭不需要的权限；对应功能可能因此无法使用。

## 数据与隐私

- 单机游戏记录和大部分设置保存在设备本地。
- 联网对战、在线 AI、网页浏览、更新检查等功能需要连接网络。
- 使用在线服务时，完成请求所需的内容会发送给相应服务。
- 卸载应用可能会清除本地记录，重要内容请先使用应用内的导出或备份功能。

## 常见问题

### 为什么有些功能需要再次下载？

夹层采用按需扩展方式。常用功能随应用提供，其他游戏或工具可以在模块商店中单独安装，这样更新某个功能时不必每次重新下载整个应用。

### 为什么更新应用时会出现安装提示？

Android 会要求你确认 APK 更新。只有在你主动安装更新时，应用才会引导你开启对应的系统安装权限；普通功能模块由应用内部管理。

### 更新后原来的数据还在吗？

使用新版 APK 直接覆盖安装通常会保留数据。卸载后重新安装则可能丢失本地数据。

### 遇到闪退、无法更新或模块安装失败怎么办？

请在应用内提交反馈，或前往 [问题反馈页面](https://github.com/3571949306/GameMatrixApp/issues)。描述问题时建议附上手机型号、Android 版本和操作步骤，但不要公开密码、令牌或其他敏感信息。
